# Demo walkthrough

This is a short walkthrough for showing Nurkhan OS to another person in about two minutes.

## 1. Overview

Open the app and start on **Overview**.

Explain the product in one sentence:

> Nurkhan OS is an AI Chief of Staff prototype that turns raw tasks, meeting notes and project context into structured actions, decisions and daily focus.

Show the four headline metrics and explain that the current version uses synthetic demo data.

## 2. Inbox

Open **Inbox** and use the pre-filled example.

Click **Structure task**.

Point out that a natural-language note becomes:

- scope
- project
- priority
- deadline
- status
- owner
- category
- next action

The product idea is that the user should not have to fill these fields manually.

## 3. Meetings

Open **Meetings** and process the sample notes.

Show how the notes are split into:

- decisions
- action items
- owners
- deadlines
- open questions

Explain that the production version would use an LLM rather than deterministic rules.

## 4. Morning Brief

Open **Morning Brief**.

Show that the system separates:

- main work priorities
- decisions required
- overdue or stuck items
- personal tasks for today
- work that can wait

The purpose is not to show every task. It is to reduce attention load.

## 5. Projects

Open **Projects** and select Project Atlas.

Show goal, strategy, metrics, blockers, risks and next actions.

Finish with **Decision history**. This is an important part of the concept: the system keeps not only what was decided, but why it was decided.

## Closing line

> The current v0.1 validates the operating model. The next step is to replace the deterministic parsers with an LLM layer and connect real data sources safely.
